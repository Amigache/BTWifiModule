BTWifiModule

FrSky Bluetooth emulator for the ESP32 — web flasher

Connection
Flashes the module through EdgeTX Passthrough (the radio’s USB port). Requirements:
  • Radio in USB Serial (VCP) mode, EdgeTX firmware built with CLI=ON + BLUETOOTH=ON.
  • Module plugged into the radio’s Bluetooth connector and running a BTWifiModule firmware with AT+DOWNLOAD.
  • Do not disconnect the radio or close this tab while flashing.
Only ESP32-C3 and ESP32-S3 modules can be flashed this way. The original ESP32 boards (DEV-38P, Pico, RadioMaster Wireless Module) lack the AT+DOWNLOAD command and are disabled in the Board list above.
