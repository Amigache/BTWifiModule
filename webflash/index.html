BTWifiModule

FrSky Bluetooth emulator for the ESP32.

Requires a Chromium-based browser (Chrome/Edge) over HTTPS or localhost, and the board connected over USB. Press RESET on the ESP32-C3 SuperMini after flashing (its native USB does not auto-reset); the CP2102 boards reset automatically.

The ESP32-S3 SuperMini, the Pico boards and the RadioMaster Wireless Module are reference builds kept for community testing: they are not hardware-validated by this project. The Pico boards differ in the radio UART pins — if one does not work, try the other.

Flashes the module through the radio's USB port (EdgeTX serial passthrough). Requirements:

  • The radio is in USB Serial (VCP) mode and its EdgeTX firmware is built with CLI=ON + BLUETOOTH=ON.
  • The module is plugged into the radio's Bluetooth connector and is running a BTWifiModule firmware that supports AT+DOWNLOAD (ESP32-C3 / S3 only).
  • Do not disconnect the radio or close the tab while flashing is in progress.

If the flash fails and the module no longer boots, recover it by plugging it into the PC over USB (or holding BOOT + pressing RESET) and flashing directly with the Direct USB mode above.
